두 영업소의 트럭이 수거 지점을 나눠 돌고 각자 영업소로 돌아온다. 상자를 실을수록 이동 연료가 비싸진다. 두 트럭의 합계 연료를 최소화하는 문제다. 정해야 할 것이 두 가지다. 어느 트럭이 어느 지점을 맡는가(부분집합)와 맡은 지점을 어떤 순서로 도는가(순열). 지점을 나누고 나면 두 트럭은 서로 영향을 주지 않는다. 그래서 영업소별로 "이 묶음을 맡으면 최소 얼마"를 표로 만들어 두고, 마지막에 서로 보완하는 묶음끼리 더한다. 학습 교재 11단원 예제 코드를 추적한 기록이며, 순서 탐색을 동적 계획법으로 바꾼 변형을 덧붙였다 (Python 3 실행 확인).

문제

영업소가 두 곳 있고 각각 트럭이 한 대씩 있다. 트럭들은 수거 지점을 나누어 방문한 뒤 자기 영업소로 돌아온다.

  • 입력: bases — 두 영업소의 (x, y) 좌표. points — 수거 지점 좌표, 최대 8개.
  • 트럭은 빈 상태로 출발하고, 지점을 들를 때마다 상자가 하나 늘어난다.
  • 이동 연료 = 맨해튼 거리 × (1 + 현재 상자 수).
  • 모든 지점은 정확히 한 번 수거된다. 한 트럭이 전혀 움직이지 않아도 된다.
  • 출력: 복귀를 포함한 두 트럭의 최소 합계 연료. 지점이 없으면 0.
구간싣고 있는 상자거리에 곱하는 값
영업소 → 첫 지점01
첫 지점 → 둘째 지점12
둘째 지점 → 셋째 지점23
k개 수거 후 → 영업소kk + 1
basespoints출력
[(10, 10), (20, 20)][(5, 5), (12, 8), (30, 30)]102

[(0, 0), (100, 0)][]0

전체 코드

minimum_fuel.py
from itertools import permutations


def minimum_fuel(bases, points):
    size = len(points)
    full = (1 << size) - 1

    def distance(a, b):
        return abs(a[0] - b[0]) + abs(a[1] - b[1])

    def costs(base):
        best = [0] * (1 << size)
        for mask in range(1, 1 << size):
            chosen = [i for i in range(size) if mask & (1 << i)]
            minimum = float('inf')
            for order in permutations(chosen):
                current = base
                boxes = 0
                fuel = 0
                for index in order:
                    fuel += distance(current, points[index]) * (1 + boxes)
                    current = points[index]
                    boxes += 1
                fuel += distance(current, base) * (1 + boxes)
                minimum = min(minimum, fuel)
            best[mask] = minimum
        return best

    cost_a, cost_b = costs(bases[0]), costs(bases[1])
    return min(cost_a[mask] + cost_b[full ^ mask]
               for mask in range(1 << size))


def run_checks():
    assert minimum_fuel([(10, 10), (20, 20)], [(5, 5), (12, 8), (30, 30)]) == 102
    assert minimum_fuel([(0, 0), (100, 0)], [(1, 0)]) == 3
    assert minimum_fuel([(0, 0), (100, 0)], []) == 0
    print("11단원: 확인용 테스트 3개 통과")


if __name__ == "__main__":
    run_checks()

핵심 아이디어

  1. 분할을 정하면 두 트럭은 독립이다 — A 트럭이 어떤 묶음을 맡을지 정해지면 B 트럭의 몫은 나머지로 자동 결정된다. 그 뒤 A가 어떤 순서로 돌든 B의 연료에는 영향이 없다.
  2. 영업소별 비용 표를 먼저 만든다 — "이 영업소의 트럭이 이 묶음을 전부 수거하고 돌아올 때의 최소 연료"를 가능한 모든 묶음에 대해 구해 둔다. 묶음 안에서는 방문 순서를 전부 시도한다.
  3. 보완하는 묶음끼리 더한다 — A의 묶음과 B의 묶음이 겹치지 않으면서 합쳐서 전체가 되는 모든 조합의 합계 중 최솟값이 답이다.

묶음을 정수 하나로 표현한다

지점이 3개면 묶음은 2³ = 8가지다. i번 지점이 묶음에 들어 있으면 i번째 비트를 1로 둔 정수(마스크)로 나타낸다.

full은 모든 비트가 1인 값이다. full ^ mask는 비트를 전부 뒤집어 "A가 맡지 않은 지점"을 한 번에 구한다. 정수이므로 리스트의 인덱스로 바로 쓸 수 있다는 점이 비트마스크의 장점이다.

판별 기준 — "여럿이 나눠 맡는다 + 각자의 몫 안에서 순서가 중요하다"는 구조이고 원소가 10개 미만이면, 부분집합 열거와 순열 열거를 겹친다. 이때 몫마다의 최적값을 표로 먼저 만들어 두면 나누는 단계와 순서를 정하는 단계가 분리된다.

코드 한 줄씩 보기

전체 집합

size = len(points)
full = (1 << size) - 1

1 << size는 2의 size제곱이고, 1을 빼면 아래 size개 비트가 모두 1이 된다. 괄호가 필요하다. 이유는 함정 절에서 다룬다.

묶음에서 지점 번호 뽑기

for mask in range(1, 1 << size):
    chosen = [i for i in range(size) if mask & (1 << i)]

mask & (1 << i)는 i번째 비트가 켜져 있을 때만 0이 아니다. mask가 0인 경우(아무것도 맡지 않음)는 best[0] = 0으로 이미 채워져 있어 1부터 돈다.

한 순서의 연료 계산

current = base
boxes = 0
fuel = 0
for index in order:
    fuel += distance(current, points[index]) * (1 + boxes)
    current = points[index]
    boxes += 1
fuel += distance(current, base) * (1 + boxes)

순서가 중요한 줄이다. 이동 연료를 먼저 더하고, 도착한 뒤에 상자를 늘린다. 지금 가고 있는 지점의 상자는 아직 싣지 않았기 때문이다. 반복문이 끝난 시점의 boxes는 수거한 전체 개수이고, 복귀 구간에는 그 값이 그대로 곱해진다.

두 표를 결합

cost_a, cost_b = costs(bases[0]), costs(bases[1])
return min(cost_a[mask] + cost_b[full ^ mask]
           for mask in range(1 << size))

mask가 0이면 B가 전부 맡고, full이면 A가 전부 맡는다. "한 트럭은 움직이지 않아도 된다"는 조건이 범위의 양 끝에 자연스럽게 들어 있다. 지점이 없으면 size가 0이라 range(1)에서 mask = 0만 돌고 0 + 0이 반환된다.

예제 추적

영업소 A (10, 10), B (20, 20). 지점 0번 (5, 5), 1번 (12, 8), 2번 (30, 30).

순서에 따라 연료가 달라진다

A가 0번과 1번을 맡는 경우의 두 순서다.

순서구간별 (거리 × 배수)연료
A → 0번 → 1번 → A10 × 1 + 10 × 2 + 4 × 342
A → 1번 → 0번 → A4 × 1 + 10 × 2 + 10 × 354

이동한 거리의 합은 둘 다 24로 같다. 차이는 긴 구간을 언제 달리느냐에서 난다. 먼 곳(0번)을 빈 차로 먼저 가고, 무거워진 마지막 복귀 구간을 짧게(거리 4) 만든 쪽이 싸다. 이 예제에서 가까운 곳부터 들르면 긴 구간(거리 10)에 가장 큰 배수 3이 붙는다.

세 줄 모두 잘못 짠 코드를 실행해 얻은 값이다.

1. 복귀 구간이 가장 비싸다

돌아올 때는 상자를 전부 실은 상태다. 복귀 거리에 (1 + boxes)를 곱하지 않으면 가장 큰 항을 통째로 빠뜨린다.

2. 상자를 늘리는 시점

boxes += 1을 연료 계산보다 앞에 두면 지점으로 가는 구간의 배수가 1씩 커진다. "이동 → 도착 → 적재" 순서를 코드 줄 순서와 맞춘다.

3. 가까운 영업소에 맡기면 된다고 생각한다

표의 세 번째 반례에서 지점 (4, 5)는 A에, (6, 5)는 B에 더 가깝다. 각자 하나씩 맡으면 27 + 27 = 54다. 그런데 A가 둘 다 맡아 (6, 5) → (4, 5) 순으로 돌면 11 × 1 + 2 × 2 + 9 × 3 = 42다. 두 지점이 서로 붙어 있어 한 대가 한꺼번에 도는 편이 왕복을 두 번 하는 것보다 싸다. 분할은 지점 하나하나를 따로 보고 정할 수 없고, 묶음 전체의 비용을 봐야 한다.

4. 역순은 같은 비용이 아니다

맨해튼 거리는 양방향이 같지만, 구간마다 곱해지는 배수가 다르기 때문에 순서를 뒤집으면 연료가 달라진다(위 추적의 42와 54). 10단원에서 본 "대칭이면 절반만 탐색" 최적화는 여기서 쓸 수 없다.

5. 연산자 우선순위

print(1 << 3 - 1)    # 4   (1 << 2로 계산된다)
print((1 << 3) - 1)  # 7

파이썬에서 뺄셈은 시프트보다 먼저 계산된다. 괄호를 빼면 full이 전혀 다른 값이 된다.

6. 결합 단계에서 순열을 다시 돌린다

비용 표는 영업소마다 한 번만 만든다. 분할을 열거하는 반복문 안에서 매번 순서를 다시 탐색하지 않는다. 표를 만들어 두면 결합은 덧셈 2ᴺ번으로 끝난다.

변형: 순서 탐색을 DP로

교재 범위를 넘어 직접 추가한 변형이다. 원본은 묶음마다 그 안의 순열을 전부 돈다. 지점 8개면 영업소 하나당 순열이 109,600개다. 10단원 글의 비트마스크 DP를 그대로 가져올 수 있는데, 조건이 하나 맞아떨어지기 때문이다. 싣고 있는 상자 수는 방문 순서와 무관하게 "지금까지 수거한 묶음의 크기"로 정해진다. 그래서 (수거한 묶음, 현재 위치)만 알면 다음 이동의 연료를 계산할 수 있다.

costs_dp.py
def distance(a, b):
    return abs(a[0] - b[0]) + abs(a[1] - b[1])


def costs_dp(base, points):
    size = len(points)
    INF = float('inf')
    # reach[mask][last]: mask를 수거하고 last에 있을 때 최소 연료
    reach = [[INF] * size for _ in range(1 << size)]
    for first in range(size):
        reach[1 << first][first] = distance(base, points[first])
    best = [0] * (1 << size)
    for mask in range(1, 1 << size):
        boxes = bin(mask).count("1")
        for last in range(size):
            fuel = reach[mask][last]
            if fuel == INF:
                continue
            for nxt in range(size):
                if mask & (1 << nxt):
                    continue
                candidate = fuel + distance(points[last], points[nxt]) * (1 + boxes)
                if candidate < reach[mask | (1 << nxt)][nxt]:
                    reach[mask | (1 << nxt)][nxt] = candidate
        best[mask] = min(reach[mask][last] + distance(points[last], base) * (1 + boxes)
                         for last in range(size) if mask & (1 << last))
    return best


def minimum_fuel_dp(bases, points):
    size = len(points)
    full = (1 << size) - 1
    cost_a, cost_b = costs_dp(bases[0], points), costs_dp(bases[1], points)
    return min(cost_a[mask] + cost_b[full ^ mask] for mask in range(1 << size))

bin(mask).count("1")이 묶음의 크기, 즉 현재 상자 수다. 한 번의 DP가 모든 묶음의 best[mask]를 함께 채우므로 원본의 costs와 같은 표가 나오고, 결합 단계는 그대로다.
