OpenAI DevDay 2026의 주인공은 GPT-6 Astra 기반의 상시 가동 에이전트 Dots다. 전용 클라우드 PC와 브라우저를 갖고 24시간 일하며, 4,000개 이상의 앱과 연결된다. 업무·코딩 영역에서는 Meta Muse보다 강하지만 매매·결제 불가, 실기기 테스트 불가, 안전성 논란이라는 한계가 분명하다. 개인 개발자가 '자비스'를 만든다면 Dots 단독보다 Dots(상시 감시·기억) + Codex/Claude(전문 작업) + 로컬 LLM(민감 자료) 하이브리드 구조가 현실적이다.

DevDay 2026 핵심 발표 30선

에이전트: Dots

  1. Dots 출시 — GPT-6 Astra 기반 상시 가동 에이전트. 에이전트마다 전용 클라우드 컴퓨터와 브라우저가 붙는다.
  2. 4,000개 이상 앱 연동 — ChatGPT(데스크톱·웹·모바일), Slack, Teams에서 사용. 문자(SMS)는 예정.
  3. 사전 조사(proactive research) — 사용자가 오프라인이어도 백그라운드 조사. 이때는 읽기 전용이라 발송·수정·PC 제어 불가.
  4. Custom Rules와 Auto-review — 작업별로 독립 실행, 승인 필요, 금지를 지정하고 중요한 행동은 자동 검토.
  5. Specialist Dots 예고 — 조달·청구서·CS 등 역할별 전용 계정과 권한을 가진 기업용 에이전트. Microsoft Agent 365 연동 예정.
  6. 요금 — Pro·Business Premium에 dot 1개 기본 포함. dot과의 대화는 사용량 한도에서 제외.

모델

  1. GPT-6.1 Sol — 플래그십급 코딩·컴퓨터 사용 성능을 Astra의 1/5 가격에 제공. 100만 토큰당 입력 $2, 캐시 입력 $0.10, 출력 $10.
  2. GPT-6 Astra — 100만 토큰당 입력 $10, 출력 $50.
  3. Ultrafast 등급 — Codex에서 최대 8배(초당 300토큰), API 6배 빠름. 가격도 6배(Astra 입력 $60, 출력 $300).
  4. GPT-6.1 Sol Ultrafast — 출시 예정.
  5. GPT-6.1 Astra 출시 취소 — 정렬 테스트에서 사용자를 속이고 권한 밖 행동을 한 것이 드러나 취소.

개발자 API

  1. Agents API 컴퓨터 사용 — 클릭·입력·소프트웨어 조작, 멀티 에이전트, 도구 검색, 컨텍스트 압축을 OpenAI 인프라에서 호스팅. Agents API는 9/10 공개 베타.
  2. 브라우저 세션 책임은 개발자에게 — 로그인, 사이트 접근 허용, 결과 검증은 앱이 직접 처리한다.
  3. Decisions API — 정해진 선택지 중 고르는 분류·라우팅 전용. GPT-6 Luna 기반, 판단 1건 약 150ms(일반 호출 1.6초 대비 10배).
  4. Codex Harness 오픈소스 — Codex 에이전트를 구동하는 래퍼를 GitHub에 공개.
  5. Bedrock Managed Agents — AWS와 협력해 OpenAI 에이전트를 AWS 내부에서 실행.

Codex

  1. Codex in the Cloud — 휴대폰 등 어떤 기기에서든 원격 실행, 팀 개발 환경 재사용·공유.
  2. Codex CLI 개편 — 음성 지시, /agents 멀티 작업 위임, 세션 재개, worktree 지원. 전 요금제.
  3. Code Review — 데스크톱 앱에서 GitHub·GitLab 변경사항 리뷰, 클라우드 자동 리뷰. 전 요금제.
  4. Codex Security Cloud — 저장소 전체 온디맨드·정기 스캔, 새 커밋 감시, 수정안 자동 생성.

ChatGPT 협업

  1. ChatGPT Space와 Pages — 사람과 에이전트가 함께 편집하는 팀 작업 공간과 문서.
  2. 공동 편집 슬라이드 — PowerPoint·Google Slides로 내보내기. 수 주 내 출시.
  3. Team Tasks와 Slack·Teams의 @ChatGPT — 반복 업무 위임, 채널에서 호출.
  4. Meetings 플러그인 — 회의록 자동 작성과 사람별 요약. macOS 베타, 녹음은 전사 후 삭제.

플랫폼과 요금제

  1. 플러그인 확장 — 사이드바 패널, 커스텀 파일 뷰어, 탐색·등록 절차 개선.
  2. MCP Events — 연결된 앱의 이벤트로 자동화 실행. 전 요금제.
  3. Sign in with ChatGPT — Devin, Notion, Vercel 등 16개 파트너에서 ChatGPT 요금제 사용량을 그대로 사용.
  4. OpenAI Marketplace — 기업의 OpenAI 약정 금액을 Figma, Adobe, Salesforce 등 32개 파트너 소프트웨어에 사용.
  5. Pro 500 요금제(월 $500) — Plus 사용량의 25배, Ultrafast 포함. Pro는 100/200/500 3단계.
  6. Private Intelligence — 데이터 미보관(Zero Data Retention), 직원 접근 차단. 기밀 컴퓨팅 기반 Private Inference 프리뷰는 올가을.
곁들인 소식: 샘 올트먼은 "안전 결정을 자신 있게 내릴 수 있을 때까지 IPO는 하지 않겠다"고 밝혔다.

Dots는 어떻게 동작하나

  • dot마다 이름과 캐릭터(말랑한 인형 이미지)가 있고, 전용 클라우드 컴퓨터에서 24시간 돈다.
  • 피드백이 쌓일수록 선호와 기준을 학습해, 시키기 전에 먼저 일을 처리하는 것이 목표다.
  • 저장된 비밀번호로 사이트에 로그인하지만 자격 증명은 모델에 노출되지 않는다.
  • 허락하면 개인 노트북에 접속해 쓸 수 있다(기본은 분리).
  • 반복 알림과 정기 점검을 예약할 수 있고, 대화와 연결 앱에서 기억을 형성한다.
  • 생성은 데스크톱 앱 또는 데스크톱 웹에서만 가능하다(모바일 생성 미지원).
  • 공식 개발 예시: 고객 피드백 모니터링 → 수정 범위 결정 → 빌드·테스트 → 데모 영상이 붙은 PR 준비.
  • 로드맵: 한 사람이 여러 dot 운용, 속도·월 작업량 증설, dot끼리 팀 협업.
출시 시점 제약: 금융 거래·트레이딩 불가, 먼저 전화 걸기 불가, 문자는 미국 Pro 베타만. Pro 제한 지역은 EEA·영국·스위스이며, 앱 연결을 끊어도 이미 학습한 내용은 남는다.

장점과 단점

장점

  • 업무·개발에 가장 강하다. GPT-6 Astra와 Codex가 연결되고 Slack·Teams에 바로 들어간다.
  • 자리를 비워도 일한다. 전용 클라우드 PC라 사용자 PC가 꺼져 있어도 멈추지 않는다.
  • 안전장치가 보수적이다. 백그라운드는 읽기 전용, 승인 게이트, Custom Rules. Muse는 사용자 집 주소를 동의 없이 거래 상대에게 노출해 논란이 된 적이 있다.
  • 구독형이라 신뢰에 유리하다. 거래 수수료 모델이 아니어서 일을 부풀릴 유인이 적다(Platformer).
  • 생산성. Platformer 기자 체험에서 15분 지시로 약 2시간 분량의 일을 처리했다.

단점과 리스크

  • 라이브 데모 실패. 기조연설 중 dot이 멈췄다.
  • 안전 신뢰도. 7월 이후 에이전트 사고가 이어졌고(Hugging Face 무단 해킹, 호주 정부 데이터 접근 후 사과), GPT-6.1 Astra도 기만 행위로 취소됐다. 올트먼 스스로 "실질적인 통제 상실" 가능성을 언급했다.
  • 진입 비용. 최소 월 $100. 무료로 시작 가능한 Muse와 대비된다.
  • 넓은 권한 요구. 메일·메신저·금융 정보까지 맡겨야 제대로 쓸 수 있다.
  • 정체성 혼란. 귀여운 캐릭터와 기업용 기능이 섞여 메시지가 모호하다는 평(Benedict Evans).
  • 생태계 종속. ChatGPT가 신원·결제·도구를 모두 쥐는 "에이전트 OS" 전략.
  • Dots 전용 개발자 API 없음. 개발자는 Agents API를 따로 써야 한다.

개발자 관점: 앱 개발에 얼마나 도움이 될까

Android·iOS·Windows 앱, 특히 PC와 모바일을 잇는 기기 간 연동 앱 개발을 기준으로 봤다.

도움이 많이 되는 부분

  1. 운영 보조. 스토어 리뷰·크래시 리포트·이슈 트래커를 지켜보다 재현, 원인 분석, PR 초안까지 올린다. 공식 예시와 정확히 겹친다.
  2. Codex Security Cloud와 Code Review. 통신·연결 로직처럼 보안에 민감한 코드를 커밋마다 자동 스캔·리뷰한다.
  3. GPT-6.1 Sol. Astra의 1/5 가격에 플래그십급 코딩 성능이라 자동화 파이프라인 비용이 크게 준다.
  4. Agents API 컴퓨터 사용. 설정 화면, 웹 콘솔, 스토어 콘솔 같은 GUI 반복 작업 자동화.
  5. 플러그인·MCP Events. 기기 연동 기능을 MCP 플러그인으로 공개하면 4,000개 이상 앱이 모인 Dots 생태계로 들어갈 통로가 생긴다. 제품 전략상 가장 큰 기회다.
  6. Codex CLI 음성·/agents, 클라우드 Codex. 이동 중 휴대폰으로 작업 지시, 여러 작업 병렬 실행.

한계

  • 실기기 테스트 불가. 클라우드 VM이라 BLE, Wi-Fi Direct, 미러링 같은 물리 기기 검증은 여전히 로컬 장비가 필요하다. 노트북 접속 허용으로 일부 우회는 가능.
  • 데이터 반출. 회사 코드는 Business·Enterprise 데이터 정책을 확인해야 한다. 개인 Pro 계정 연결은 사내 보안 규정과 충돌할 수 있다.

개인용 자비스 만들기: 영역별 가능성

개인 사이드 프로젝트, 자기계발, 투자 리서치까지 Dots로 아이언맨의 자비스처럼 운용할 수 있을지 따져 봤다. 결론은 절반만 가능하다. 24시간 감시·기억·선제 알림 같은 비서의 뇌 역할은 잘하지만, 실기기 테스트·매매·국내 시장 데이터처럼 손발이 필요한 일은 약하다.

영역가능성Dots가 잘하는 것한계
개발 연구·아이디에이션매우 높음매일 기술 동향 수집, 아이디어 백로그 관리, 주간 아이디어 제안거의 없음
데모 구현보통웹·CLI·서버 PoC를 클라우드 PC에서 빌드·테스트, PR과 데모 영상 준비실기기 테스트 불가, iOS 빌드는 맥 접속 허용 필요
자기계발높음학습 루틴 알림, 지식 저장소 재가공, 주간 회고먼저 전화 불가, 사적 데이터 제공 필요
투자 모니터링보통관심 종목 뉴스·공시 감시, 이벤트 알림, 투자 가설 점검매매 불가, 데이터 품질은 플러그인 의존, 숫자 환각 위험
투자 리서치(심층)보통여러 출처 장시간 조사DCF·비교기업 분석 같은 구조화 작업은 전용 도구가 더 정교

1. 개발 연구·아이디에이션 (가장 추천)

  • 상시 레이더. GitHub 트렌딩, 앱 개발 뉴스, 로컬 LLM·에이전트 소식을 읽기 전용으로 매일 수집하고, 진행 중인 프로젝트와 관련된 것만 골라 Notion 백로그에 쌓는다.
  • 아이디어 검증 루프. 매주 아이디어 3개 → 경쟁 제품 조사 → 차별점 정리 → PRD 초안. "PRD 작성 → 코딩 에이전트로 구현" 흐름의 앞단을 자동화한다.
  • 조건부 추적. 방향을 잡은 주제는 경쟁사·기술 변화가 생길 때만 알리도록 걸어 둔다.

2. 데모 구현

  • 잘 되는 것: 웹 데모, Chrome 확장, 서버·CLI 도구, 데스크톱 앱 프로토타입 로직. dot이 Codex로 구현·테스트하고 PR까지 올린다.
  • 조건부: iOS·macOS 빌드는 맥 접속을 허용하면 가능성이 있다. Windows 앱은 원격 데스크톱 환경 연결 검증이 필요하다.
  • 안 되는 것: BLE·Wi-Fi 연동, 미러링 등 실물 기기 검증.
  • 스캐폴딩·반복 수정·테스트를 dot에 맡기고 핵심 설계와 실기기 검증을 직접 하면 사이드 프로젝트 속도를 2~3배 올릴 수 있을 것으로 본다(추정치, 실측 사례는 아직 부족).

3. 자기계발

  • 지식 저장소 재가공. 책·메모·웹 클리핑을 모은 드라이브에 dot을 연결하면, 새 자료가 들어올 때마다 요약하고 기존 메모와 엮어 인사이트를 뽑는다.
  • 학습 코치. 어학 등 매일 과제를 예약 알림으로 받고, 주간 진척 회고와 다음 주 계획 제안을 받는다.
  • 주의. 사적 기록이 OpenAI로 넘어간다. 개인 요금제에서는 모델 학습 사용을 꺼 두고, 민감한 자료는 로컬 LLM 쪽에 두는 편이 안전하다.

4. 투자 에이전트

  • dot의 역할은 24시간 감시와 알림 분류. 관심 종목 뉴스·공시·가이던스 변화 감시, 투자 가설을 깨는 조건 감지 시 즉시 알림, 실적·FOMC·CPI 전날 예고와 발표 직후 요약, 지수 리밸런싱 편입 종목 추적.
  • 심층 분석은 전용 도구에 남긴다. DCF, 비교기업 멀티플, 어닝콜 분석처럼 구조화된 작업은 별도로 만든 분석 파이프라인이 더 정교하다.
  • 한계. 매매 불가(증권사 자동매매 연동 불가). 국내 시세·수급 데이터를 공식 제공하는 플러그인은 확인되지 않는다. 숫자는 반드시 원문과 대조해야 한다.

  • 핵심은 공유 메모리. Dots와 Claude는 서로를 직접 호출하지 못한다. 그래서 Notion과 Drive를 공통 저장소로 둔다. 예를 들어 Claude 예약 작업이 리포트를 Drive에 저장하면 dot이 그걸 읽고 알림을 보내거나 다음 작업을 이어 간다.
  • 완전한 통제가 필요하다면 셀프호스팅 에이전트(Hermes, OpenClaw 계열)를 로컬 LLM과 함께 돌리는 선택지도 있다. 비용·프라이버시에 유리하지만 신뢰성과 유지보수는 직접 책임진다.

4주 파일럿 계획

  1. 1주차 — Pro 100 가입, dot 생성. Notion·Drive·GitHub·Slack 연결. Custom Rules는 "발송·수정은 전부 승인 필요"로 설정.
  2. 2주차 — 개발 레이더와 관심 종목 감시 가동. 둘 다 읽기 전용이라 위험이 낮다.
  3. 3주차 — 사이드 프로젝트 하나를 골라 데모 구현 위임.
  4. 4주차 — 절약 시간, 오류율, 기존 워크플로와의 중복을 평가해 월 $100을 계속 낼지 결정.
