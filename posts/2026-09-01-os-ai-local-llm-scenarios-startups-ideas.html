1. 왜 지금인가: 하드웨어 티어와 경제성

2026년의 변화는 "로컬에서 돌아간다"가 아니라 "로컬에서 돌아가는 모델이 쓸 만해졌다"이다. MoE 구조(gpt-oss-120b, Qwen3 235B-A22B, DeepSeek 계열)가 대용량 유니파이드 메모리와 궁합이 맞으면서, 디코드 속도가 메모리 대역폭 ÷ 활성 파라미터로 결정되는 Mac 계열이 대화·에이전트 루프에 유리해졌다. Apple은 2026-08-25 M5 Max/M5 Ultra Mac Studio를 "온디바이스 AI를 위한 궁극의 데스크톱"으로 발표했고, 4대 클러스터 시 단일 대비 최대 3배 추론을 공식 언급했다.

경제성: 개인은 클라우드가 싸다

API 바닥가는 입력 $0.20/M 수준까지 내려왔다(2026-07 OpenAI 인하 이후, 단일 출처). SitePoint의 12개월 TCO(2026-08)에서 50만 토큰/일 개인 사용자는 OpenAI API $1,260, 오픈웨이트 API $360, 로컬(M4 Ultra) $6,457로, 100만 토큰/일 미만 개인·프로슈머는 클라우드가 경제적이라는 결론이다. 팀 단위 500만 토큰/일에서 18~24개월에 패리티가 온다.

따라서 로컬 LLM의 정당화 근거는 비용이 아니라 다음 네 가지다.

  • 연속 스트림 데이터 — 카메라·마이크·화면 이력은 토큰 수가 폭발하고, 클라우드 전송 자체가 프라이버시 문제가 된다. Limitless는 Meta 인수 직후 EU·영국·한국 등에서 즉시 서비스를 종료했고, OpenAI Codex "Chronicle"은 스크린샷을 비암호화 클라우드로 보낸다는 비판을 받았다.
  • 24시간 상주 에이전트 — OpenClaw 같은 상시 에이전트는 API 과금이 예측 불가능하다. Mac mini M4 idle 8~12W, 연 전기료 약 $15 수준이 대안이 된다.
  • 가족·다중 기기 허브 — 폰·태블릿·TV·카메라가 하나의 홈 모델을 공유하는 구조는 클라우드 구독을 사람 수만큼 사는 것보다 단순하다.
  • 정책·가용성 헤지 — 모델 변경, 가격 인상, 지역 차단, 인터넷 단절에 대한 보험.

4. 스타트업 지형 25선과 OpenClaw 이후

4-1. OpenClaw에 무슨 일이 있었나

OpenClaw는 2025-11 Peter Steinberger가 "Warelay"로 시작해 Clawdbot → Moltbot → OpenClaw(2026-01-30)로 이름을 바꾼, 메신저(Telegram·WhatsApp·Discord)를 인터페이스로 PC 작업을 대행하는 로컬 상주 에이전트다. 2026-05 GitHub 323k+ 스타로 역대 6위, 주간 신규 인스턴스 약 450만 건을 기록했고 Tim Cook이 2026-05 실적발표에서 Mac mini/Studio 품절의 원인으로 "에이전트 툴 수요"를 언급할 정도였다.

그 다음이 중요하다. 2026-02 Steinberger는 OpenAI에 합류해 "Claw Labs"를 이끌고, 프로젝트는 비영리 재단(2026-07 501(c)(3), 스폰서 OpenAI·GitHub·NVIDIA)으로 넘어갔다. 보안 사고가 잇따랐다. Cisco가 3,000여 개 스킬 중 386개를 악성으로 확인했고, 2026-07에만 CVE 14건 이상(MCP 루프백 정책 우회, 심링크 샌드박스 탈출)이 나왔다. 핵심 설계 결함은 스킬 API 키가 샌드박스가 아닌 호스트 에이전트 프로세스에 주입된다는 점이었다.

결과적으로 OpenClaw는 세 갈래로 분화했다. 8주 만에 4개 재작성 프로젝트(Nanobot·ZeroClaw·PicoClaw·NanoClaw)가 합계 116k 스타를 모았고, 대기업은 "안전한 클로" 패키징으로 상품화했으며(NVIDIA NemoClaw, Cisco DefenseClaw, Tencent ClawPro, Microsoft ClawPilot, Google Remy), Nous Research의 Hermes Agent(214k 스타, 3계층 메모리, 워크플로를 자동으로 스킬로 추상화)가 2026-06 OpenRouter 일일 토큰에서 OpenClaw를 추월했다. Sequoia 집계로 OpenClaw 주변 생태계 스타트업은 168개, 합산 월 매출은 약 $40만이다. 열기에 비해 돈은 아직 작다.

4-3. 관찰되는 패턴 7가지

  1. 폼팩터가 소프트웨어보다 먼저 정해졌다. OpenClaw가 "개인 에이전트 = 상주형 Mac mini"를 대중화했고, Perplexity·Hyperbox·Sequoia(파트너들에게 각인 Mac mini 200대 배포)가 그 폼팩터를 전제로 움직인다.
  2. 오픈소스 코어 + 클라우드/호스팅 과금이 지배적 BM이다. Ollama·Hermes·Mem0·Cua·Screenpipe 모두 같은 구조다. 코드는 무료, 운영 편의가 유료.
  3. 하이브리드 라우팅이 새 레이어가 됐다. Conifer, NemoClaw 프라이버시 라우터, Ollama Cloud, Apple의 온디바이스→PCC 3계층까지 "쉬운 건 로컬, 어려운 건 클라우드"가 기본값이다. 순수 로컬만 고집하는 곳은 소수.
  4. 로컬을 택하는 진짜 이유는 비용이 아니다. 상시 에이전트의 예측 불가 API 비용, 화면·음성 상시 기록의 규제(GDPR), 규제 산업 컴플라이언스가 순서대로 온다. 속도는 부차적이다.
  5. 메모리 레이어는 통폐합 중. 소비자 앱(Rewind·Limitless)은 빅테크에 흡수됐고, 남은 독립 플레이어는 "에이전트에 컨텍스트를 공급하는 MCP/파일 기반 인프라"로 포지션을 옮겼다. 소비자 앱보다 개발자 인프라가 생존했다.
  6. 보안이 최대 병목이자 대기업의 진입로. 악성 스킬과 프롬프트 인젝션 사고 이후 "안전한 클로" 패키징이 대기업 상품화의 표준 방식이 됐다.
  7. 런타임 계층은 통합·인수 단계. llama.cpp → Hugging Face, Ollama $88M을 제외하면 LM Studio·Msty·Jan·Pinokio는 소규모 부트스트랩이다. 런타임 자체로는 돈이 안 되고, 위(에이전트)나 아래(하드웨어)에서 수익이 난다.

5. AI OS가 제공할 수 있는 서비스 프리미티브

Karpathy의 2023년 "LLM OS" 은유(LLM=CPU, 컨텍스트=RAM, 임베딩=디스크, 도구=주변기기)는 2025~26년에 실제 OS 벤더의 로드맵이 됐다. 그가 2025-06 YC 강연에서 "지금은 클라우드에 단말로 접속하는 1960년대 시분할 단계이고 개인용 컴퓨팅 혁명은 아직 오지 않았다"고 말했는데, 256GB 유니파이드 메모리 Mac이 바로 그 "개인용 LLM 컴퓨터"의 첫 세대다. 벤더 발표, 오픈소스 Agent OS 프로젝트, 보안 사고에서 추출한 프리미티브를 정리하면 다음과 같다.

6. 아이디에이션: 비어 있는 자리

조사 결과를 겹쳐 보면 채워진 자리와 빈 자리가 보인다. 아래는 팩트가 아니라 내 해석이다.

6-1. 이미 붐비는 곳

  • 런타임·챗 UI — Ollama, LM Studio, Jan, Open WebUI, Msty. 신규 진입 의미 없음.
  • 범용 데스크톱 에이전트 본체 — OpenClaw 포크 4종, Hermes, Simular, 대기업 "클로". 프레임워크 자체로 차별화 어려움.
  • macOS 로컬 전사 — MacWhisper, Superwhisper, Hyprnote. 포화.
  • 화면 기억(Recall류) — 규제·보안 리스크가 커서 개인 개발자가 지기 어려운 영역. Screenpipe가 개발자 인프라로 남은 것이 시사적.

6-2. 비어 있거나 개발자 수준에 머문 곳

빈 자리현재 상태왜 비었나

승인·감사 UX — 에이전트의 결과적 행동을 폰에서 승인하고 로그를 읽는 인터페이스각 프레임워크의 CLI/채팅 내 yes/no프레임워크 개발자들은 모델·도구에 집중, UX는 후순위

6-3. AI OS 서비스 아이디어 (벤더가 아직 안 한 것)

  • 위임 프로필(Delegation Profile) — "출장 중", "야간 배치", "아이 사용" 같은 상황별 권한 번들. 승인 피로를 개별 승인이 아니라 정책으로 푼다. Windows의 6개 폴더 고정 범위보다 한 단계 위.
  • 서명된 스킬 스토어 — 앱 스토어처럼 스킬·MCP 서버에 코드 서명·권한 매니페스트·리뷰를 강제. OpenClaw 재단이 하지 못한 일이고, OS가 하면 자연스럽다.
  • 가구(Household) 신원 — Apple Family Sharing, Google Family Link 위에 "가족 공유 모델·메모리·승인 체계"를 얹는 계층.
  • 에너지·열 스케줄러 — 배터리·전기요금·팬 소음을 고려해 무거운 에이전트 작업을 야간이나 충전 중으로 미루는 OS 스케줄링. 모바일에서는 이미 Doze가 하는 일의 에이전트 버전.
  • 컨텍스트 이식성 — 메모리·선호·승인 이력을 표준 포맷으로 내보내고 다른 기기·모델로 옮기는 권리. Limitless 종료 때 사용자들이 겪은 문제의 해법.
  • 기기 간 모델 협업 — 폰 온디바이스 모델이 프리필·분류를 하고 홈 허브가 디코드를, 클라우드가 검증을 맡는 계층 분업. Exo의 분산 추론을 이기종 기기로 확장한 것.

7. 앱 개발자가 할 수 있는 아이디어 12선

기준은 셋이다. 런타임이나 에이전트 본체를 다시 만들지 않는다. 3사가 2026년에 연 API(Foundation Models, Windows AI APIs·MCP ODR, ML Kit Prompt API·AppFunctions)를 활용한다. 1인 또는 소규모 팀이 6개월 안에 첫 버전을 낼 수 있어야 한다. 앞 6개는 기기 연동 경험을 살리는 쪽, 뒤 6개는 범용이다.

우선순위

시장 증거·차별화·구현 난이도를 겹치면 세 개가 남는다.

  1. #1 Home Brain Relay — 수요는 LM Link와 OpenClaw 폰 조작 사례로 증명됐고, 기기 발견·페어링·gRPC 스트리밍·E2E는 연동 앱 개발자가 이미 가진 무기다. 여기에 온디바이스 폴백을 붙이면 "인터넷 없어도 되는 개인 AI"라는 한 줄 설명이 된다. Windows까지 지원하는 곳이 없다.
  2. #2 Approval Inbox — 보안 사고 이후 가장 명확한 페인포인트이고, 프레임워크들이 후순위로 미루는 UX 문제라 경쟁이 적다. 어떤 에이전트가 이기든 승인 인터페이스는 필요하다. 위임 프로필 개념이 차별점.
  3. #6 Hub Console — 난이도가 가장 낮고, 허브 운영자라는 좁지만 열성적인 시장이 지금 생기고 있다. #1·#2로 가는 관문 상품으로 적합하다.

이 세 개는 하나의 앱 패밀리가 될 수 있다. 콘솔(운영) → 릴레이(사용) → 승인(신뢰)으로 확장하면, "집에 있는 Mac을 개인 AI 서버로 만드는 모바일 앱"이라는 하나의 포지션이 된다. 지난달 AI PC 앱 아이디에이션에서 나온 Spark Companion·Home AI Node·Local AI Relay와도 같은 방향이다.

피해야 할 것 — 특정 프레임워크(OpenClaw 등)에 종속된 설계. 8주 만에 포크 4종이 116k 스타를 모았고, 토큰 점유율 1위가 Hermes로 바뀌었다. 백엔드는 어댑터로 두고 프로토콜(MCP·Wyoming·OpenAI 호환 API)에 붙어야 한다.

8. 정리

질문답
OS + AI 유저 시나리오는 무엇이 있나오늘 출시된 것은 통역·화면 컨텍스트 요약·설정 에이전트·온디바이스 개발자 API 수준. 개인 맥락 Siri·Copilot Actions·Gemini Intelligence 같은 "에이전틱" 기능은 2026년 하반기 베타~한정 출시. 홈·엣지는 오픈소스 스택으로 이미 구현 가능하나 설치 난이도가 높다.
OpenClaw 이후 스타트업은 어디로 갔나에이전트 본체는 포크·대기업 패키징으로 분산, 돈은 하이브리드 라우팅(Conifer·Ollama Cloud), 컨텍스트 인프라(Mem0·Screenpipe), 컴퓨터 사용 인프라(Cua·Simular)로 이동. 소비자 메모리 앱은 빅테크에 흡수됐다.
AI OS가 제공할 서비스는도구 레지스트리·에이전트 신원·capability 권한·격리 워크스페이스·개인 컨텍스트 인덱스·모델 라우터·감사 로그·씬 클라이언트 프로토콜 14종. 3사 모두 레지스트리와 격리는 시작했고, 승인 UX·다중 사용자·컨텍스트 이식성은 비어 있다.
앱 개발자의 기회는런타임이 아니라 그 위. 씬 클라이언트(Home Brain Relay), 승인·감사 UX(Approval Inbox), 허브 운영(Hub Console)이 우선순위. Windows 로컬 생산성과 에이전트 발견성 도구(Intent Forge)가 차순위.
로컬 LLM 시장 크기는토큰 단가로는 개인은 클라우드가 싸다. 로컬은 상시 에이전트·연속 스트림 데이터·가족 허브·규제 헤지의 니치이고, 그 니치가 Mac mini 품절을 만들 만큼은 커졌다.

다음 단계로는 #1 Home Brain Relay의 프로토콜 설계(기기 발견 → 페어링 → gRPC 스트리밍 → 온디바이스 폴백)를 별도 글로 정리할 계획이다.
