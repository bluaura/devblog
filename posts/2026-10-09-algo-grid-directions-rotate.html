DIRECTIONS = ((-1, 0), (-1, 1), (0, 1), (1, 1),

각 원소는 (행 변화량, 열 변화량)이다. 위쪽 (-1, 0)에서 시작해 시계 방향으로 8개를 나열했다. 행 번호는 아래로 갈수록 커지므로 위쪽이 -1이다. 수학 좌표계의 y축과 반대라는 점이 처음에 가장 헷갈린다.

(-1, -1) 좌상(-1, 0) 상(-1, 1) 우상
(0, -1) 좌현재 칸(0, 1) 우
(1, -1) 좌하(1, 0) 하(1, 1) 우하

시작 칸 (r, c)에서 방향 (dr, dc)로 k걸음 간 칸은 (r + dr × k, c + dc × k)다. 이 식 하나로 직선 위의 모든 칸을 표현한다.

문제 1 — 8방향 패턴 세기

격자에서 주어진 숫자 순서가 8방향 직선 위에 연속해서 나타나는 횟수를 센다. 겹친 패턴도 각각 센다.

count_pattern.py
def count_pattern(grid, pattern):
    rows, columns = len(grid), len(grid[0])
    count = 0
    for r in range(rows):
        for c in range(columns):
            for dr, dc in DIRECTIONS:
                matched = True
                for step, value in enumerate(pattern):
                    nr, nc = r + dr * step, c + dc * step
                    if not (0 <= nr < rows and 0 <= nc < columns):
                        matched = False
                        break
                    if grid[nr][nc] != value:
                        matched = False
                        break
                if matched:
                    count += 1
    return count

구조

  1. 모든 칸을 패턴의 시작점 후보로 본다.
  2. 시작점마다 8방향을 각각 시도한다.
  3. step번째 숫자가 step걸음 간 칸의 값과 같은지 차례로 확인한다. 범위를 벗어나거나 값이 다르면 즉시 포기한다.
  4. 끝까지 통과한 (시작점, 방향) 쌍의 개수가 답이다.

enumerate(pattern)이 걸음 수와 기대값을 한 번에 준다. step이 0일 때는 시작 칸 자신을 검사하므로 시작 칸에 대한 별도 조건이 필요 없다.

예제 추적

[[1, 2, 3], [0, 0, 0], [3, 2, 1]]에서 [1, 2, 3]을 찾는다.

시작점방향지나는 칸결과
(0, 0)우 (0, 1)(0,0) (0,1) (0,2)일치
(0, 0)우하 (1, 1)(0,0) (1,1)(1,1)이 0이라 실패
(2, 2)좌 (0, -1)(2,2) (2,1) (2,0)일치
(2, 2)상 (-1, 0)(2,2) (1,2)(1,2)가 0이라 실패

일치는 2건이므로 답은 2다. 아래 행은 오른쪽에서 왼쪽으로 읽어야 1, 2, 3이 된다. 8방향을 모두 돌기 때문에 역방향도 자연스럽게 잡힌다.

놓치기 쉬운 함정

상황입력결과설명
앞뒤가 같은 패턴[[1, 2, 1]], [1, 2, 1]2같은 칸들이 양쪽 끝에서 한 번씩 세어진다
겹치는 패턴[[1, 1, 1]], [1, 1]4위치 2곳 × 방향 2개
길이 1 패턴[[1]], [1]8한 칸이 8방향 모두에서 일치로 세어진다
  • 범위 검사가 값 비교보다 먼저다. 순서가 바뀌면 nr이 -1일 때 파이썬이 에러 없이 마지막 행을 읽는다. 격자 반대편과 이어진 것처럼 잘못 세게 된다.
  • 길이 1은 입력 조건으로 막혀 있다. 문제가 "길이 2 이상"을 명시한 이유가 위 표의 세 번째 줄이다. 조건이 없는 변형이라면 따로 처리해야 한다.
  • 회문 패턴의 중복은 문제 정의를 확인한다. 이 문제는 "겹친 패턴도 센다"이므로 2가 맞다. 같은 칸 집합을 한 번만 세라는 문제라면 방향을 4개만 쓰는 식으로 바꿔야 한다.

시간 복잡도는 O(R × C × 8 × L)이다 (L은 패턴 길이). 불일치 시 바로 빠져나오므로 실제로는 더 적게 돈다.

문제 2 — 테두리 반시계 회전

행렬의 각 테두리(바깥 고리, 그 안쪽 고리, …)의 값을 반시계 방향으로 한 칸씩 옮긴 새 행렬을 반환한다. 원본은 유지하고, 한 행이나 한 열만 남은 부분은 움직이지 않는다.

rotate_ccw.py
def rotate_ccw(matrix):
    grid = [row[:] for row in matrix]
    rows, columns = len(grid), len(grid[0])
    for layer in range(min(rows, columns) // 2):
        top, left = layer, layer
        bottom, right = rows - 1 - layer, columns - 1 - layer
        carried = grid[top][left]
        for r in range(top + 1, bottom + 1):
            grid[r][left], carried = carried, grid[r][left]
        for c in range(left + 1, right + 1):
            grid[bottom][c], carried = carried, grid[bottom][c]
        for r in range(bottom - 1, top - 1, -1):
            grid[r][right], carried = carried, grid[r][right]
        for c in range(right - 1, left - 1, -1):
            grid[top][c], carried = carried, grid[top][c]
    return grid

구조

  • 복사본에서 작업 — [row[:] for row in matrix]로 행마다 복사한다. matrix[:]만 쓰면 바깥 리스트만 복사되어 원본 행이 함께 바뀐다.
  • 고리 개수 — min(rows, columns) // 2. 3×3이면 1개(가운데 칸은 고리가 아님), 4×4면 2개, 1×N이면 0개라 아무것도 움직이지 않는다.
  • 값을 들고 걷는다 — 왼쪽 위 값을 carried에 들고, 왼쪽 변을 내려가고 → 아래 변을 오른쪽으로 → 오른쪽 변을 올라가고 → 위 변을 왼쪽으로 돌아온다. 칸마다 들고 있던 값을 내려놓고 그 칸의 원래 값을 집어 든다.
grid[r][left], carried = carried, grid[r][left]

파이썬은 오른쪽을 먼저 전부 계산한 뒤 왼쪽에 대입한다. 그래서 임시 변수 없이 "내려놓기와 집어 들기"가 한 줄로 된다.

놓치기 쉬운 함정

  • 모서리를 두 번 처리한다. 네 구간의 범위가 각각 top + 1, left + 1, bottom - 1, right - 1에서 시작하는 이유다. 앞 구간이 끝난 모서리는 다음 구간에서 건너뛴다. 한 고리에서 처리하는 칸은 정확히 2 × (높이 + 너비) − 4개다.
  • 마지막 구간이 시작 칸까지 와야 한다. 위 변의 범위 끝이 left - 1이라 (top, left)까지 포함된다. 여기서 빠뜨리면 왼쪽 위 칸에 원래 값이 그대로 남는다.
  • 회전 방향과 걷는 방향을 혼동한다. 값을 들고 걷는 방식에서는 걷는 방향이 곧 값이 이동하는 방향이다. 반시계로 돌리려면 반시계로 걷는다. 결과에서 위 행이 왼쪽으로 밀렸는지(2, 3이 앞으로 왔는지)로 확인한다.
  • 직사각형에서 고리 수를 잘못 센다. 3×4는 고리 1개이고 안쪽에 1×2가 남는데, 이 부분은 움직이지 않는다. 실행 결과는 [[2, 3, 4, 8], [1, 6, 7, 12], [5, 9, 10, 11]]로 6, 7이 제자리다.

문제 3 — 한 방향 포위와 폭탄

칸 하나를 터치해 값을 new_value(0 또는 1)로 바꿨을 때, 그 칸 다음부터 지도 끝까지 한 방향으로 늘어선 값들이 어떻게 바뀌는지 구한다. 2는 폭탄이다.

조건결과
방향 안에 new_value가 없다그대로
첫 new_value 앞에 폭탄이 없다그 앞까지만 new_value로 변경 (포위)
첫 new_value 앞에 폭탄이 있다방향 끝까지 전부 new_value로 변경
capture_ray.py
def capture_ray(values, new_value):
    result = list(values)
    end = None
    has_bomb = False
    for index, value in enumerate(values):
        if value == new_value:
            end = index
            break
        if value == 2:
            has_bomb = True
    if end is None:
        return result
    stop = len(values) if has_bomb else end
    for index in range(stop):
        result[index] = new_value
    return result

구조: 판정 먼저, 수정은 나중

  1. 판정 — 앞에서부터 훑으며 첫 new_value의 위치 end를 찾는다. 그 전에 지나친 폭탄이 있었는지를 has_bomb에 기록한다. 찾는 즉시 break하므로 그 뒤의 폭탄은 보지 않는다.
  2. 범위 결정 — 닫아 줄 new_value가 없으면 아무것도 하지 않는다. 있으면 폭탄 유무에 따라 stop을 end 또는 리스트 끝으로 정한다.
  3. 수정 — 0부터 stop 직전까지 한꺼번에 바꾼다.

예제

valuesnew_value판정결과
[0, 2, 1, 0]1end = 2, 앞에 폭탄 있음[1, 1, 1, 1]
[0, 1, 2, 0]1end = 1, 앞에 폭탄 없음[1, 1, 2, 0]
[0, 2, 0]1new_value 없음[0, 2, 0]
[1, 0, 0]1end = 0, 바꿀 칸 없음[1, 0, 0]
[0, 0, 0]1new_value 없음[0, 0, 0]

놓치기 쉬운 함정

  • 훑으면서 바로 바꾼다. 닫아 줄 값이 있는지 모르는 상태에서 수정하면, 끝까지 가서 없다는 것을 알았을 때 되돌려야 한다. 판정이 끝난 뒤 수정하면 되돌릴 일이 없다.
  • 폭탄이 있기만 하면 터진다고 본다. [0, 2, 0]처럼 폭탄은 있지만 닫아 줄 new_value가 없으면 아무 일도 일어나지 않는다. end is None 검사가 폭탄 처리보다 먼저다.
  • 첫 new_value 뒤의 폭탄까지 센다. [0, 1, 2, 0]의 폭탄은 포위 구간 밖이라 무시된다. break가 이를 보장한다.
  • 폭탄 칸 자체도 바뀐다. 폭탄이 터지면 폭탄 칸과 end 뒤쪽 칸까지 전부 new_value가 된다. stop이 end가 아니라 리스트 길이인 이유다.
  • 입력 리스트를 직접 고친다. result = list(values)로 복사한 뒤 복사본만 수정하고, 판정은 원본 values로 한다.

격자에서 한 방향 값을 뽑는 방법

이 함수는 1차원 리스트만 받는다. 격자에서 그 리스트를 만드는 부분은 앞의 좌표 공식 그대로다. 직접 추가한 보조 코드다.

def ray_cells(rows, columns, r, c, dr, dc):
    cells = []
    r, c = r + dr, c + dc
    while 0 <= r < rows and 0 <= c < columns:
        cells.append((r, c))
        r, c = r + dr, c + dc
    return cells


print(ray_cells(3, 4, 1, 1, 0, 1))    # [(1, 2), (1, 3)]
print(ray_cells(3, 4, 1, 1, -1, -1))  # [(0, 0)]

좌표 목록으로 값을 읽어 capture_ray에 넘기고, 반환된 리스트를 같은 좌표 순서로 다시 써넣으면 된다. 2차원 문제를 "좌표 목록 뽑기 → 1차원 처리 → 되돌려 쓰기"로 나누는 방식이다.

변형: 테두리를 리스트로 뽑아 k칸 회전

교재 범위를 넘어 직접 추가한 변형이다. 같은 분리 방식을 회전에 적용하면 한 칸이 아니라 k칸 회전도 같은 코드로 처리된다. 고리의 좌표를 반시계 순서로 나열해 두면, 회전은 1차원 리스트를 미는 일이 된다.

rotate_ccw_k.py
def ring_cells(top, left, bottom, right):
    cells = [(r, left) for r in range(top, bottom + 1)]
    cells += [(bottom, c) for c in range(left + 1, right + 1)]
    cells += [(r, right) for r in range(bottom - 1, top - 1, -1)]
    cells += [(top, c) for c in range(right - 1, left, -1)]
    return cells


def rotate_ccw_k(matrix, k=1):
    grid = [row[:] for row in matrix]
    rows, columns = len(grid), len(grid[0])
    for layer in range(min(rows, columns) // 2):
        cells = ring_cells(layer, layer, rows - 1 - layer, columns - 1 - layer)
        values = [matrix[r][c] for r, c in cells]
        shift = k % len(cells)
        for index, (r, c) in enumerate(cells):
            grid[r][c] = values[index - shift]
    return grid


print(rotate_ccw_k([[1, 2, 3], [4, 5, 6], [7, 8, 9]], 1))
# [[2, 3, 6], [1, 5, 9], [4, 7, 8]]
print(rotate_ccw_k([[1, 2, 3], [4, 5, 6], [7, 8, 9]], 3))
# [[6, 9, 8], [3, 5, 7], [2, 1, 4]]

index번째 칸에는 shift칸 앞에 있던 값이 들어온다. index - shift가 음수가 되어도 파이썬의 음수 인덱스가 리스트 뒤쪽을 가리키므로 고리가 자연스럽게 이어진다. 범위 검사에서는 함정이었던 성질이 여기서는 도움이 된다. k % len(cells)로 줄여 두었기 때문에 k가 아무리 커도 고리 길이만큼만 일한다.

검증 항목조건결과
k = 1일 때 원본 함수와 일치1×1 ~ 6×6 무작위 3만 건전부 일치
k칸 회전 = 원본 함수 k번 적용k는 0 ~ 30전부 일치
원본 행렬 보존, 값 구성 동일같은 입력전부 통과
count_pattern 독립 구현 대조패턴 길이 2 ~ 4, 3만 건전부 일치

한 방향 포위첫 동일값 위치와 그 앞의 폭탄 여부를 먼저 판정판정 중에 수정, 닫는 값 없이 폭탄 처리
  • 방향은 (dr, dc) 튜플 목록으로 한 번만 정의하고 반복문으로 돌린다. 방향별로 코드를 복사하지 않는다.
  • 범위 검사는 항상 격자 접근보다 먼저다. 파이썬의 음수 인덱스는 에러를 내지 않는다.
  • 원본을 보존해야 하면 2차원은 행 단위로 복사한다.
  • 2차원 조작이 복잡하면 좌표 목록을 뽑아 1차원 문제로 바꾼 뒤 되돌려 쓴다.
