Gemini 4 Carbon이란

Carbon은 Gemini 4 계열의 두 번째 공개 모델이다. 10월 초 Google 내부 코딩 플랫폼(Jetski)에서 테스트 중이라는 보도로 처음 알려졌고, 당시 한 Google 직원이 코딩 체감이 Claude Opus 5.5와 비슷하다고 평가해 주목받았다. 9월 30일 발표된 Gemini 4 Argon 이후 약 2주 만에 나온 후속작이다.

Google은 Carbon을 며칠씩 이어지는 장기 자율 개발 작업과 사이버보안(취약점 탐지, 검증, 패치) 용도에 맞춰 설계했다고 설명한다. 내부에서는 대형 코드베이스의 원인 분석과 미묘한 버그 수정을 여러 날 연속으로 수행했다고 한다.

출시 현황과 가격

  • 접근: 초기에는 Google의 Fairwind 프로그램에 선정된 보안 전문가에게만 제공된다. 일반 개발자 대상 공개 일정은 발표되지 않았다.
  • API 스펙: 모델 ID, 컨텍스트 길이, 최대 출력 등 세부 사양은 아직 공개되지 않았다. 참고로 Argon은 입출력 합산 100만 토큰 이상의 컨텍스트를 지원한다.
  • 가격: 도입가 입력 $2, 출력 $10(100만 토큰 기준), 캐시 입력 95% 할인. 이후 $4 / $20으로 인상 예정이며 도입가 종료 시점은 미정이다.
  • 지금 쓸 수 있는 모델: Gemini 4 Argon(10월 13일 일반 공개, AI Studio와 Android Studio 지원).

앱 개발자 관점의 장점

  • 대형 코드베이스 분석: 256K~1M 토큰 구간 긴 컨텍스트 추론에서 경쟁 모델 대비 20%p 이상 앞선다. 레거시 프로젝트 전체를 넣고 구조를 파악하는 작업에 유리하다.
  • 보안 코드 작성: SEC-bench Pro 88.2%, CWE-bench 71.0%, ExploitGym 54.8%로 GPT-6 Astra와 Argon을 앞선다. Google 내부 기준으로 안전한 코드 생성 성공률이 Argon의 2배 이상이다.
  • 비용 효율: AA 지수 과제당 비용이 Opus 5.5보다 약 23% 저렴하다. Arena의 Agent Arena에서도 중앙값 과제 비용이 1위 Opus 5.5보다 72% 낮았다.
  • 웹 프론트엔드: WebDev Arena에서 4위(1,769)로 Argon 대비 크게 개선되었다.
  • 프롬프트 인젝션 방어: Gray Swan 간접 프롬프트 인젝션 테스트에서 공격 성공률 0.0%를 기록했다. 에이전트가 외부 문서나 웹을 읽는 구조에서 의미가 있다.

앱 개발자 관점의 단점

  • 지금 쓸 수 없다: 공개 API가 없고 일정도 미정이다. 당장 비교 테스트를 하려면 Argon으로 대신해야 한다.
  • 에이전트 코딩은 Opus 5.5 우위: 코딩 도구 안에서 동작을 측정하는 Coding Agent Index에서 Claude Code + Opus 5.5(62)에 3점 뒤진다.
  • 실제 SW 엔지니어링은 Astra와 Opus에 열세: FrontierSWE 2에서 세 모델 중 최하위다.
  • UI 자동화(컴퓨터 사용): OSWorld 오프라인 서브셋에서 Opus 5.5가 약 6%p 앞선다. 앱 UI 자동 테스트 같은 용도라면 고려할 부분이다.
  • 느린 응답: Argon 대비 추론 토큰이 2.3배, 출력 토큰이 64% 많다. 일부 과제는 처리 시간이 2배 이상 걸렸다. 빠른 반복 작업에는 불리하다.
  • 환각률 상승: Argon 4%에서 11%로 올랐다. 다만 Opus 5.5와 Astra(각 50%)보다는 여전히 크게 낮다.
