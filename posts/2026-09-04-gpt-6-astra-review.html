개요와 스펙

OpenAI의 새 플래그십 모델. "세계에서 가장 지능적이고 정렬된 모델"이라는 슬로건으로 발표됐고, 텍사스 Stargate 사이트에서 10만 개 이상의 GPU로 학습했다. Greg Brockman은 컴퓨터 사용 능력을 두고 "AGI 시대의 시작"이라고 표현했다. 표준 모델과 Astra Pro(Pro·Business·Enterprise 전용) 두 가지 변형으로 나뉜다.

제품 측면에서는 Codex에 컨텍스트 윈도우 간 "노트 유지" 시스템이 들어갔다. 컨텍스트가 넘칠 때 요약으로 압축하는 대신 누적된 세부 사항을 메모로 보존하고, 이전 컨텍스트를 검색해 요구사항이나 테스트 결과를 다시 꺼내 볼 수 있다. 모호한 지시에서 적절한 판단을 내리는 능력, 중간에 추가된 요구사항을 원래 목표를 잃지 않고 반영하는 능력도 개선됐다고 OpenAI는 설명한다.

사이버보안 분야에서는 OpenAI Preparedness Framework의 "Critical" 등급에 처음으로 도달했다. 평가 중 미공개 제로데이 취약점 2건을 발견해 메인테이너에 보고했고, 익스플로잇 작성 같은 고급 기능은 Daybreak 프로그램에서 별도 승인을 받아야 활성화된다. 기본 배포 모델은 보안 코드 리뷰·패치 같은 방어적 작업만 허용한다.

벤치마크를 읽을 때 주의할 점

  • HLE는 Astra가 지는 유일한 학술 항목이고, 발표문에는 언급이 없다.
  • OSWorld 2.0에서 OpenAI 표는 Fable 5.1 칸을 비워뒀다. llm-stats 집계에서는 Fable 5.1이 77.9%로 Astra(72.6%)보다 높다. 컴퓨터 사용 "정확도"만 놓고 보면 Astra가 압도한다고 보기 어렵다.
  • ARC-AGI-3 99.9%는 OpenAI 커스텀 하니스 기준이다. 기본 하니스에서는 62.7%다(Simon Willison 지적). 보도에 따라 98.6%로도 나온다.
  • FrontierMath는 OpenAI가 개발 자금을 댔고 일부 문제에 독점 접근권이 있다.
  • BenchCAD의 Claude 수치는 "수정된 평가 설정"으로 측정됐다고 OpenAI가 각주로 밝혔다.
  • ExploitGym은 통상 6시간 제한을 해제하고 측정했고, 보안 수치는 Daybreak 접근 기준이라 프로덕션 모델과 다르다.
  • 모든 수치가 max effort라 실사용 지연·토큰 비용은 표보다 크다.

Computer Use

이번 출시에서 OpenAI가 가장 강조한 영역이다. ChatGPT 데스크톱 앱(Mac)에서 백그라운드로 동작하며 이전 대비 약 2배 빠르고, API에서도 computer use 툴이 web search·file search·code interpreter·MCP와 함께 정식 지원된다.

안전성 측면에서는 적대적으로 구성된 컴퓨터 사용 테스트에서 의도치 않은 부작용이 2.4%(Sol 22.0%, Claude 5.1 9.5%)였고, AutoReview를 붙이면 1.8%로 내려간다. AutoReview 거부를 우회하려는 시도는 테스트 중 0건이었다. 데모에서는 작업 시작 20초 후 멈추고 되묻는 장면이 있는데, 모호한 지시를 처리하는 방식이 달라졌다는 신호로 읽힌다.

경쟁 구도 — computer use는 Anthropic이 2024년 먼저 개척한 영역이다. OSWorld 2.0 정확도는 제3자 집계상 Fable 5.1이 여전히 앞서고, 속도(작업당 시간)와 실무형 태스크(AutomationBench, ScreenSpot-Pro)는 Astra가 확실히 앞선다. 에이전트 비용은 실행 시간에 비례하므로 속도 우위는 곧 비용 우위다.

사용자 후기

긍정

  • Claire Vo (Lenny's Newsletter) — 6개월간 모든 모델로 실패한 ChatPRD 코딩 태스크가 90% 성공. Blender 3D 에셋과 Mac 데스크톱 앱을 원샷으로 완성. Figma·Flora 같은 실제 업무 툴에서 computer use가 "데모가 아니라 실무"로 느껴진다는 평.
  • Matt Shumer — 의도 파악과 모호한 지시 처리가 크게 나아졌고 백엔드 엔지니어링에 강함. 브라우저 작업을 "클릭 하나하나 안 보고 맡겨도 된다"며 Claude에서 Astra로 기본 모델을 교체. 외출 중 서버 장애를 스스로 복구한 사례를 공유.
  • 커뮤니티 (AINews) — 컴퓨터 사용이 "코딩의 그 순간"에 근접했다는 반응. 3D 공간 추론 호평. 소수 간격 문제의 최장 간격을 246에서 186으로 줄여 1930년대 이후 첫 진전을 낸 사례가 수학계에서 화제.

부정

  • 출시 파행 — 유료 구독자보다 인플루언서가 먼저 접근. Altman이 X에서 사과하고 지연 일수만큼 사용량 리셋 크레딧을 보상. 9월 5~6일 주말 접근을 목표로 하되 보장은 없다고 밝힘.
  • 가격 — 토큰 단가 2.5배 인상. 일반 사용자와 단순 작업에는 비추천, 모델 라우팅(쉬운 작업은 저가 모델, 실패 비용이 큰 작업만 Astra) 권장이 공통된 의견.
  • 속도와 자율성 — 모델 크기 탓에 다소 느리다. 장기 자율 프로젝트는 세부에 매몰되는 경향이 여전해 조율 장치가 필요.
  • 시각 결과물 — 디자인·이미지 직접 생성은 Claude가 여전히 우위. Astra는 Unreal Engine처럼 기존 툴과 에셋을 활용하는 쪽에 강함.
  • 모니터링 가능성 후퇴 — 장기 사이버 작업의 최대 80%에서 추론 요약이 나오지 않는다는 보고. OpenAI 수석과학자도 Sol보다 추론을 감시하기 어렵다고 인정. 안전 연구자들은 "더 순종적이면서 내부를 들여다보기는 어려워진" 모델이라고 비판.

공식 소개 영상

Introducing GPT-6 Astra (OpenAI, 2분 43초). 벤치마크 설명 없이 데모 시연으로만 구성돼 있다. 스크립트를 확인한 시연 순서는 다음과 같다.

  1. 노란 원 그리기 → 로켓 창문으로 변환 → Blender에서 3D 모델화 → 3D 프린터용 STL 파일 생성
  2. 소매업체용 우비 시즌 프레젠테이션 제작, 재킷 색에 맞춰 배경색 변경
  3. 다운로드 폴더의 사진을 첨부해 eBay에 중고 테이블 등록, 흠집 있음을 설명에 반영
  4. 방향키 이동·스페이스 부스트로 소행성을 피하는 3D 게임 제작
  5. 지난주 주문한 식당에서 음식 재주문
  6. 로펌용 라이선스 계약서 초안 작성 후 책임 제한 조항을 라이선서에 유리하게 수정
  7. Lower Haight 지역 테니스 코트 검색 후 오후 5시 예약

핵심 메시지는 여러 작업을 동시에 병렬로 맡기는 멀티태스킹 에이전트이며, 설명란에 "최상의 성능은 ChatGPT 데스크톱 앱에서"라고 명시돼 있다. 국내 채널 중에서는 코드팩토리, 김단테 채널의 해설 영상이 함께 올라와 있다.

앱 개발자 관점 API 메모

  • Claude Fable 5.1과 가격($10/$50)·컨텍스트(약 1M)·출력(128K)이 사실상 동일하므로 모델 선택은 벤치마크가 아니라 자기 워크로드 테스트로 결정해야 한다. 실패하는 태스크 하나를 동일한 툴·추론 설정으로 두 모델에 돌려보는 것이 가장 빠르다.
  • 캐시 읽기 $1/M는 저렴하지만 캐시 쓰기 $12.5/M는 입력 단가보다 높다. 시스템 프롬프트가 크고 재사용률이 낮으면 캐시가 오히려 손해다.
  • Batch/Flex 50% 할인은 실시간이 아닌 배치성 작업(로그 분석, 대량 분류)에서 가격 격차를 상당 부분 상쇄한다.
  • Enterprise 워크스페이스는 기본 비활성화 상태로 시작하므로 팀 계정은 관리자가 켜야 한다.
  • 익스플로잇·멀웨어 분석 계열 요청은 기본 모델이 거부한다. 보안 도구를 만든다면 Daybreak 프로그램 승인이 선행돼야 한다.
  • 이 글의 스펙은 2026-09-04 기준이며 롤아웃 중이라 요금·제한은 바뀔 수 있다.
