Muse는 무엇인가

Muse는 메타의 소비자용 개인 AI 에이전트다. 사용자의 앱과 서비스에 연결해 일상 업무를 대신 처리하는 것이 목표이며, 메타가 챗봇을 넘어 에이전트로 전환하는 핵심 제품이다.

공개된 기능은 다음과 같다.

  • 이메일 발송, 여행·숙소·식당 예약
  • 공과금·구독료 인하 협상, 각종 양식 작성
  • 레시피 기반 장보기 리스트 생성, 파티 초대장 발송
  • Stripe Link 연동 결제 (일회용 카드로 구매 보호)
  • 대화에서 학습한 내용을 바탕으로 한 능동적 제안, "잊어라" 명령으로 삭제

연동 가능한 서비스는 이메일, 캘린더, 결제, 건강·피트니스 앱, 스마트홈, 외식(OpenTable), 쇼핑, 음악(Spotify), 이벤트(Ticketmaster), Google Workspace, Apple Health, Meta 자체 앱 등이다. 공개 API가 있는 서비스는 커넥터로 추가할 수 있다.

기술 구조와 보안 설계

항목내용
모델Muse Spark 1.3 (9월 2일 공개). 1M 컨텍스트, 코딩·에이전트 태스크 중심 튜닝. 메타 발표 기준 콜당 비용 20% 감소, 토큰 사용 25% 감소
실행 환경사용자당 전용 "Muse Secure VM". 에이전트는 systemd-nspawn 컨테이너 안에서 실행되며 내장 브라우저를 갖는다
접근 제어별도 감시 에이전트 Sentinel이 외부 접근을 게이트키핑. 읽기/쓰기 권한을 태스크·서비스·거래·기간 단위로 분리
승인 정책민감한 행동은 사용자 승인 필요, 저위험 작업은 자동 실행. "반사적 승인"으로 보안이 무너지는 것을 막기 위한 설계
자격 증명에이전트는 비밀번호·결제수단에 직접 접근 불가 (surrogate credential 방식)
데이터광고 시스템과 미공유 선언. 기본값은 쿼리를 메타가 활용하되 사용자가 끌 수 있음. 메타도 볼 수 없는 Confidential VM은 연내 예정
신뢰 리스크 — 메타는 2019년 FTC 50억 달러 벌금, 2023년 재위반 기소, 2026년 8월 아동 안전 관련 180억 달러 주정부 합의 이력이 있다. 내부 테스트에서 에이전트가 iCloud 사진을 노출한 사고가 있었다는 보도도 있다. 아키텍처가 좋아도 신뢰는 별개 문제다.

한국 출시 — 현재 미국 전용이며 국제 출시 일정은 공개되지 않았다. 연동 서비스도 OpenTable, Ticketmaster 등 미국 서비스 중심이라 한국에 열리더라도 초기 활용도는 제한적일 수 있다.

Muse vs Grok Bot

xAI의 Grok Bot은 2026년 8월 출시된 컴퓨터 사용 에이전트다. 같은 "에이전트"지만 지향점이 다르다. 한 줄로 요약하면 Muse는 "내 비서", Grok Bot은 "내 팀"이다.

타깃일반 소비자의 생활 관리지식노동자·팀 (영업·운영·개발)
구조사용자당 전용 VM + Sentinel 게이트멤버당 호스팅 컴퓨터 1대를 여러 봇이 공유
핵심 차별점낮은 진입장벽, WhatsApp, 결제 대행멀티 에이전트 오케스트레이션(봇 간 위임), 화면 녹화를 스킬로 변환, 트리거·스케줄 루틴, 24시간 실행

다른 에이전트와의 비교

OpenClaw (오픈소스, 로컬 실행)

오스트리아 개발자 Peter Steinberger가 만든 오픈소스 에이전트로, Warelay → Clawdbot → Moltbot → OpenClaw로 이름이 바뀌었다. 2026년 2월 제작자가 OpenAI에 합류하며 OpenClaw Foundation이 관리한다. TypeScript·Swift로 작성되었고 Telegram·Signal·Discord로 제어하며, SKILL.md 기반 스킬 시스템을 쓴다.

  • 장점 — 무료, 모델 자유 선택(Claude·GPT·DeepSeek), 데이터가 내 기기에 남음, 8월 30일 v2.0으로 설정·UI 개선. 개발자에게 가장 유연하다.
  • 단점 — 보안이 기본값이 아니다. v2.0도 시크릿 미암호화·샌드박스 비활성이 지적되었고, Cisco 조사에서 서드파티 스킬의 데이터 유출·프롬프트 인젝션 사례가 확인됐다. 중국은 공공기관·은행의 사용을 제한했다. 유지보수 부담이 커서 "사용자를 PM으로 만든다"는 평가가 있다.

Google Gemini Spark (2026년 5월 I/O)

  • 장점 — Gmail·Docs·Workspace와 가장 깊은 통합. 전용 Gmail 주소로 에이전트에게 이메일을 보낼 수 있고, Chrome으로 웹에 접근하며 MCP를 지원한다.
  • 단점 — AI Ultra 구독자 대상 테스트 단계. 연동 서비스가 아직 제한적이다.

Claude Cowork

  • 장점 — 데스크톱·로컬 파일 중심 워크플로우. SSO·SCIM·감사 로그 등 엔터프라이즈 기능.
  • 단점 — 제공되는 커넥터 범위에 의존한다.

ChatGPT (Work / Agent)

  • 장점 — 단일 세션 결과물 품질이 높고, 웹·모바일·데스크톱을 모두 지원하며 스케줄 태스크가 있다.
  • 단점 — 대화 간 컨텍스트 공유가 없고 네이티브 멀티 에이전트 조정이 없다.

실제로 유용할 유즈케이스

메타가 공개한 구체적 데모는 적다(예산 내 유모차 추천 후 결제 정도). 공개된 연동 서비스와 기능을 기준으로 현실적인 활용 가능성을 정리하면 다음과 같다.

  1. 이메일·일정 실행 — 받은편지함을 읽고 할 일을 추출해 답장 작성·발송, 회의 조율. 초안을 주는 것이 아니라 보내는 것까지 한다는 점이 챗봇과 다르다.
  2. 예약·구매 대행 — 식당, 공연, 숙소, 항공 예약과 쇼핑 결제. 조건만 주면 브라우저를 열어 폼을 채우고 결제까지 완료한다. 결제 실패·환불 등 예외 처리 품질은 아직 데이터가 없다.
  3. 생활 행정 자동화 — 공과금 협상, 신청서 작성, 초대장 발송, 레시피를 장보기 리스트로 변환. 메타가 "대신 협상한다"를 명시한 것이 특징이다.
  4. 건강·습관 관리 — Apple Health 등 피트니스 앱 연동으로 개인화된 플랜을 짜고 진행을 스스로 추적한다.
  5. 스마트홈 — 기기 제어 연동이 목록에 있지만 구체 데모는 없다.
  6. 메신저 인터페이스 — 별도 앱 없이 WhatsApp 대화창에서 지시한다. AI 글래스 연동은 예정.
공통 한계 — 브라우저 조작 방식은 사이트 레이아웃 변경, MFA, 세션 만료에 취약하다. 무료 티어는 사용량 제한이 있어 24시간 상시 실행은 유료가 필요할 가능성이 크다.

개발자 관점

Muse 본체는 코딩용이 아니다. 코딩과 에이전트 개발은 별도 제품 Muse Code와 Meta Model API(Spark 1.3 제공)로 분리되어 있어서, Claude Code 대체로 기대하면 실망할 가능성이 크다.

반대로 자기 앱을 에이전트 툴로 노출하는 관점에서는 흥미롭다. Muse는 공개 API가 있는 서비스를 커넥터로 붙일 수 있어, 예를 들어 PC-모바일 연동 앱을 Muse가 호출하는 시나리오가 이론상 가능하다. 다만 서드파티 커넥터 SDK의 공개 여부는 아직 확인되지 않았다.

지금 한국에서 비슷한 경험을 미리 해보려면 OpenClaw(로컬 실행, 보안 설정을 직접 챙겨야 함)나 ChatGPT의 스케줄 태스크·에이전트가 현실적인 선택지다.

메타의 승부수는 "무료 티어 + 커머스 수익"이다. 광고 대신 거래 수수료 모델로 전환할 수 있는지, 그리고 Confidential VM으로 신뢰 문제를 넘을 수 있는지가 관전 포인트다. 한국 출시가 열리면 직접 써보고 후기를 올릴 예정이다.
