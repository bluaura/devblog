앱 개발자 관점 12선

1. Foundation Models: LanguageModel 프로토콜로 프로바이더 스왑

새 LanguageModel 프로토콜 하나로 온디바이스 모델(SystemLanguageModel), Private Cloud Compute(PrivateCloudComputeLanguageModel), Claude, Gemini, 커스텀 모델이 모두 LanguageModelSession의 백엔드가 된다. Anthropic과 Google이 공식 Swift 패키지를 배포했고, SPM 의존성만 바꾸면 하위 코드는 그대로다. 응답의 usage 프로퍼티로 토큰 과금 추적도 가능하다.

UsageTracking.swift (세션 예시, 미검증)
let response = try await session.respond(to: prompt)
print(response.usage.input.totalTokenCount)
print(response.usage.input.cachedTokenCount)
print(response.usage.output.totalTokenCount)
print(response.usage.output.reasoningTokenCount)

2. Private Cloud Compute 무료 개방

App Store Small Business Program 기준, 개발자 전체 앱의 누적 첫 다운로드가 200만 미만이면 PCC의 차세대 Apple Foundation Model을 클라우드 API 비용 없이 쓸 수 있다. 32K 컨텍스트, reasoningLevel(.light / 기본 / .deep) 추론 모드, API 키와 계정 설정 불필요. watchOS 27에서도 호출 가능하다.

3. 온디바이스 모델 재구축과 멀티모달

온디바이스 모델이 이미지 입력을 받는다. UIImage, CGImage, Core Image 타입, CVPixelBuffer, 파일 URL을 프롬프트에 첨부하면 되고 크롭 없이 임의 크기를 받는다. Vision 프레임워크 기반 OCRTool과 BarcodeReaderTool이 내장됐고, 컨텍스트는 8,192 토큰, 가드레일 오탐이 줄었다. 최상위 온디바이스 모델은 iPhone 17 Pro / iPhone Air가 필요하다.

4. Dynamic Profiles: 에이전틱 프리미티브

하나의 세션 안에서 앱 상태에 따라 Instructions·Tools·모델·추론 레벨을 선언적으로 바꾸는 API다. 대화 히스토리를 유지한 채 모드를 전환하므로 직접 컨텍스트를 오케스트레이션하는 보일러플레이트가 줄어든다.

CraftProfile.swift (세션 예시, 미검증)
struct CraftProfile: LanguageModelSession.DynamicProfile {
    let states: CraftProjectStates

    var body: some DynamicProfile {
        switch states.mode {
        case .craftAnalysis:
            Profile {
                Instructions { "사진 속 공예품을 분석한다." }
                RecordImageAnalysisTool()
            }
        case .brainstorm:
            Profile {
                Instructions { "아이디어를 확장한다." }
                BrainstormRecordTool()
            }
            .model(states.privateCloudCompute)
            .reasoningLevel(.deep)
        }
    }
}

let session = LanguageModelSession(profile: CraftProfile(states: states))

5. Foundation Models 오픈소스와 툴체인

코어 프레임워크가 오픈소스로 공개되어 Linux 서버를 포함한 Swift 실행 환경 어디서나 동작한다. Utilities 패키지에는 Skill API, Chat Completions 표준 인터페이스, 트랜스크립트 관리용 Profile 모디파이어가 들어가며 OS 릴리스 사이에도 업데이트된다. macOS 27에 fm CLI, 데이터 과학자용 Python SDK(apple_fm_sdk), 비결정적 모델의 품질을 정량 측정하는 Evaluations 프레임워크가 추가됐다.

fm_sdk_example.py (세션 예시, 미검증)
import apple_fm_sdk as fm

model = fm.SystemLanguageModel()
is_available, reason = model.is_available()

if is_available:
    session = fm.LanguageModelSession(model=model)
    response = await session.respond(prompt="Hello!")

6. Core AI 프레임워크

자체 모델(LLM·비전·멀티모달)을 온디바이스에서 돌리기 위한 신규 OS 프레임워크. 메모리 안전 Swift API, PyTorch 변환 툴, AOT 컴파일, zero-copy 데이터 경로, 상태 유지 실행을 제공하며 서버·토큰 비용이 없다. CoreAILanguageModel(Neural Engine)과 MLXLanguageModel(Mac GPU)로 Foundation Models 세션에 그대로 꽂힌다. MLX는 Metal 4와 Thunderbolt RDMA 기반 다중 Mac 분산 학습을 지원한다.

7. Xcode 27 에이전틱 코딩

Anthropic·OpenAI·Google 모델로 라우팅하고, Agent Client Protocol로 Claude Code 같은 외부 에이전트를 플러그인처럼 붙이며, MCP로 툴을 연결한다. /plan 명령으로 구현 전 스코핑, 서브에이전트 병렬 실행, 아티팩트 패널, 시뮬레이터 조작·테스트 실행·Organizer 크래시 수정 제안까지 IDE 라이프사이클 전반에 에이전트가 들어갔다. Apple이 직접 만든 Agent Skills 7종(SwiftUI, UIKit 현대화, 테스트, 보안 감사, C 바운드 안전성, 디바이스 조작 등)이 마크다운으로 동봉되어 외부 툴에서도 읽을 수 있다.

8. Xcode 27 IDE 변화

Simulator를 대체하는 Device Hub(시뮬레이터와 실기기 통합, devicectl CLI), 설치 용량 30% 감소, Apple Silicon 전용, iCloud 설정 동기화, 프로젝트별 테마, 이름 없이 바로 시작하는 Untitled 프로젝트가 추가됐다. Organizer에는 스토리지·애니메이션 히치 메트릭과 에이전트 추천, Instruments에는 Top Functions 뷰가 들어갔고 Xcode Cloud 빌드는 최대 2배 빨라졌다.

9. Swift 6.4

anyAppleOS 가용성 축약, defer 블록 내 await, 마이그레이션용 경고 억제, 타입체커 진단 개선. OS 커널 일부가 Swift로 작성됐다는 언급이 있었다. Swift Testing이 권장 표준이고 XCTest는 레거시로 분류된다.

10. SwiftUI

커스텀 컨테이너 드래그 재정렬, 리스트 밖 스와이프 액션, 레이아웃 리사이즈 2배, lazy state 초기화, AsyncImage 자동 캐싱, 디스크 직접 접근 문서 앱 인프라가 추가됐다.

주의 — @State가 프로퍼티 래퍼에서 매크로로 바뀌었다. 선언부와 init에서 동시에 초기값을 주면 init 값이 버려지고, private @State 멤버가 있으면 자동 생성 이니셜라이저가 꺼지며, 다른 프로퍼티 래퍼와 조합할 수 없다.

11. App Intents가 새 Siri의 유일한 진입로

Entity 스키마와 Intent 스키마로 앱 콘텐츠를 Spotlight 시맨틱 인덱스에 기여하면 Siri가 특정 발화 문구 등록 없이 자연어로 앱 데이터를 찾고 실행한다. View Annotations API로 화면 요소를 엔티티에 매핑하면 "이거 공유해" 같은 온스크린 참조가 가능하고, App Intents Testing 프레임워크로 UI 자동화 없이 시스템 경로를 검증한다. SiriKit(INExtension)은 공식 폐기되어 컴파일은 되지만 새 Siri에 노출되지 않는다.

사용자 관점 10선

13. Siri AI

Google Gemini 모델을 기반으로 다시 만들었다. 대화형 후속 질문 카드, 화면 인식 액션, Dynamic Island 애니메이션, 텍스트·이미지 생성과 파일 분석이 되는 전용 앱, 음성 표현력·속도 커스텀이 특징이다. 대기자 명단 방식으로 열리며 영어 우선, EU와 중국은 제외다. 지원 기기는 iPhone 15 Pro 이상과 16 시리즈, M1 이상 iPad·Mac, Vision Pro, Apple Watch Series 10·Ultra 2·SE 3.

14. macOS 27 Golden Gate

Spotlight에서 바로 Siri 대화를 시작하고, 사이드바가 화면 끝까지 확장되며 컬러 아이콘이 붙었다. 앱 간 통일된 툴바, 좁아진 창 코너 반경, 아이콘 리프레시, iPhone Mirroring 창 리사이즈와 DRM 영상 재생, 5K Mac 미러링이 포함된다.

15. Liquid Glass 조정

사용자가 투명도를 직접 조절하는 슬라이더가 생겼고 콘텐츠 확산과 가장자리 음영으로 가독성을 보강했다. 도입 1년 만의 사실상 후퇴 조정이다.

16. 성능

앱 실행 최대 30%, AirDrop 전송 최대 80%, 사진 로딩 최대 70%, Mail 로딩과 Apple Music 재생 시작 최대 80% 개선을 주장했고 CPU 스케줄러 변경이 구형 기기에 유리하다. iOS 27은 iPhone 11까지 지원하지만 iPadOS, watchOS(Series 8·Ultra 1·SE 2), tvOS는 구형 기기 지원을 끊었다.

17. 자녀 보호 전면 개편

13세 미만은 자녀 계정이 필수이고 18세까지 확장할 수 있다. Ask to Browse와 Ask to Buy가 기본값이며, 엔터테인먼트·게임·소셜 카테고리별 Time Allowances, 재설계된 Screen Time, iPhone 없이 설정하는 자녀용 Apple Watch가 추가됐다.

18. Apple Intelligence 앱 기능

Safari 탭 자동 정리와 웹페이지 변경 알림, AI 확장 생성. Passwords 앱이 취약하거나 유출된 비밀번호를 원탭으로 교체하는 에이전틱 동작. Calendar 자연어 일정 생성, Messages·Mail의 문체 모방 답장, 통화 중 Mail·Messages 컨텍스트 표시.

19. 사진과 이미지

Reframe(원근 재조정), Extend(생성형 확장), 강화된 Cleanup. Image Playground는 포토리얼 이미지와 배경화면을 생성하되 사용자 사진으로 학습하지 않으며 SynthID 워터마크가 붙는다. Genmoji 개편, 키워드 태깅, 슬라이드쇼 메이커.

20. iPadOS 27

iPhone 앱 리사이즈, 옵션 상시 메뉴바, 홈 화면 편집 undo·redo, 초대형 위젯, Sidecar 터치 확대, 창 전환 속도 개선.

21. watchOS 27과 visionOS 27

Watch는 동적 앱 그리드, 탭 제스처, 배터리 효율과 걸음 정확도, Wallet 게스트 키. Vision Pro는 웨이크워드 없는 3D 오브 형태의 공간 Siri, 파노라마의 몰입 환경 변환, 곡면 창, 4K 캡처. 개발 측면에서는 Mac에서 Vision Pro로 실시간 전송하는 Spatial Preview, 서드파티 트래킹 하드웨어용 Spatial Accessories, Gaussian Splatting 렌더링, Windows PC와 CloudXR을 잇는 Foveated Streaming, Godot 엔진 지원이 눈에 띈다.

22. 그 밖의 체감 항목

FaceTime 듀얼 카메라, Notes 마크다운 복사와 Mac 드로잉, iCloud 공유 앨범의 Android·Windows 참여와 원본 해상도, AirPods 커스텀 EQ, CarPlay 영상 앱, Health 갱년기 추적, Wallet 패스 생성, Home 4K 녹화와 멀티 카메라, Maps 자연어 경로 검색.

AI 생산성 관점 8선

23. Shortcuts 자연어 생성

프롬프트로 워크플로를 작성하고 Apple Intelligence 액션을 결합한다. 노코드 자동화의 진입 장벽이 크게 낮아졌다.

24. Siri 크로스앱 컨텍스트 실행

앱을 열지 않고 App Intents로 액션을 체이닝하고 화면 위 콘텐츠를 참조해 "이 문서 요약해서 그에게 보내" 같은 요청을 처리한다. 대화 기록은 iPhone·iPad·Mac·Vision Pro 간 iCloud로 동기화된다.

25. Spotlight 시맨틱 인덱스, 개인용 RAG

앱이 콘텐츠를 기여하면 Siri가 그 데이터로 답한다. 개발자 쪽에서는 Foundation Models의 Spotlight 툴로 외부 벡터 DB 없이 완전 로컬 RAG를 구현할 수 있다.

26. fm CLI와 Python SDK

fm chat으로 대화하고 셸 파이프에 끼워 요약·추출·생성 스크립트를 만든다. 로컬 LLM 워크플로를 터미널에서 무료·오프라인으로 돌리는 셈이다.

terminal (개념 예시, 미검증)
# 대화형
fm chat

# 파이프라인에 끼워 쓰기
git log --since="1 week ago" --oneline | fm "이번 주 변경사항을 릴리스 노트 형식으로 요약해줘"

27. 전역 받아쓰기와 작문 도구

맞춤법·구두점·대문자 자동 교정, 서드파티 앱 내 교정과 작성 제안, VoiceOver 이미지 설명 강화, Accessibility Reader의 요약과 번역.

28. Xcode 로컬라이제이션 에이전트

코드베이스를 분석해 String Catalog를 만들고 전체 UI 문자열을 번역한 뒤 TestFlight로 원어민 피드백까지 받는 흐름이 에이전트로 자동화됐다. 언어별 스타일 가이드를 적용할 수 있어 다국어 출시의 비용 구조가 달라진다.

29. Xcode Organizer와 Instruments 에이전트

크래시 로그를 바탕으로 수정을 제안하고, 행 rate·배터리·스토리지·히치 같은 메트릭 목표 대비 추천을 생성한다. Instruments의 Top Functions 뷰로 가장 비싼 코드 경로를 즉시 찾는다.

30. Game Porting Toolkit 4와 Apple Agent Skills

Metal 최적화 지식을 에이전트 스킬 형태로 오픈소스 배포한다. Apple이 직접 "에이전트용 가이드의 저자"가 된 첫 사례로, 커뮤니티 문서 대신 프레임워크 제작자의 지식을 에이전트가 참조하게 됐다.
