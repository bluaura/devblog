문제 1 — 연결 구역 크기

상하좌우로 같은 값이 이어진 칸들을 한 구역으로 본다. 대각선은 연결이 아니다. 모든 구역의 크기를 모아 오름차순으로 반환한다.

component_sizes.py
from collections import deque


def component_sizes(grid):
    rows, columns = len(grid), len(grid[0])
    visited = [[False] * columns for _ in range(rows)]
    sizes = []
    for sr in range(rows):
        for sc in range(columns):
            if visited[sr][sc]:
                continue
            color = grid[sr][sc]
            visited[sr][sc] = True
            queue = deque([(sr, sc)])
            size = 0
            while queue:
                r, c = queue.popleft()
                size += 1
                for dr, dc in ((-1, 0), (1, 0), (0, -1), (0, 1)):
                    nr, nc = r + dr, c + dc
                    if not (0 <= nr < rows and 0 <= nc < columns):
                        continue
                    if visited[nr][nc] or grid[nr][nc] != color:
                        continue
                    visited[nr][nc] = True
                    queue.append((nr, nc))
            sizes.append(size)
    return sorted(sizes)

구조

  1. 바깥 이중 반복 — 모든 칸을 차례로 본다. 이미 방문한 칸은 어떤 구역에 속해 세어진 칸이므로 건너뛴다.
  2. 새 구역 시작 — 미방문 칸을 만나면 그 칸의 값을 color로 기억하고 BFS를 시작한다.
  3. 같은 색만 확장 — 이웃이 범위 안이고, 미방문이고, color와 같을 때만 큐에 넣는다.
  4. 꺼낼 때 센다 — 큐에서 꺼낼 때마다 size를 1 올린다. 큐가 비면 그 값이 구역의 크기다.

visited는 BFS마다 새로 만들지 않고 전체가 공유한다. 그래서 BFS가 여러 번 돌아도 각 칸은 한 번만 큐에 들어가고, 전체 시간은 O(R × C)다.

(0,1), (1,1), (1,2)는 바깥 반복에서 다시 만나지만 이미 방문 상태라 건너뛴다. 발견 순서는 3, 2, 1이고 정렬 후 [1, 2, 3]이다. (1,0)의 2는 (0,2)·(1,2)의 2와 색은 같지만 이어져 있지 않아 별도 구역이다.

놓치기 쉬운 함정

  • 같은 색을 한 구역으로 합친다. [[1, 2], [2, 1]]의 답은 [2, 2]가 아니라 [1, 1, 1, 1]이다. 대각선은 연결이 아니므로 네 칸이 모두 따로다. 색별 개수를 세는 문제가 아니다.
  • 방문 표시를 꺼낼 때 한다. 넣을 때 표시하지 않으면 같은 칸이 여러 이웃에게서 중복으로 큐에 들어가 크기가 실제보다 크게 나온다.
  • 크기를 두 군데서 센다. 넣을 때 세든 꺼낼 때 세든 한 곳에서만 센다. 이 코드는 꺼낼 때만 세므로 시작 칸도 따로 더할 필요가 없다.
  • 재귀 DFS로 푼다. 논리는 같지만 파이썬은 재귀 깊이 제한이 있다. 1×2000짜리 한 줄 격자를 재귀 DFS에 넣으면 기본 제한(1000)에서 RecursionError가 났고, 이 BFS 코드는 [2000]을 반환했다.
  • 정렬을 빠뜨린다. 발견 순서는 격자 배치에 따라 달라진다. 출력 형식이 오름차순이므로 마지막에 sorted가 필요하다.

전처리 — 약수 개수

행성 문제의 이동 조건에 약수 개수가 쓰인다. BFS 도중에 매번 계산하면 느리므로 1부터 9999까지 미리 표로 만든다.

divisor_counts.py
def divisor_counts(limit):
    counts = [0] * (limit + 1)
    for divisor in range(1, limit + 1):
        for multiple in range(divisor, limit + 1, divisor):
            counts[multiple] += 1
    return counts


print(divisor_counts(8)[1:])  # [1, 2, 2, 3, 2, 4, 2, 4]

"n의 약수를 찾는다"를 뒤집어 "d를 약수로 갖는 수는 d의 배수들이다"로 본다. d = 1은 모든 수에, d = 2는 짝수에, d = 3은 3의 배수에 1씩 더한다. 나눗셈과 나머지 연산이 하나도 없고, 안쪽 반복은 limit / d번만 돈다.

방식 (limit = 9999)안쪽 반복 횟수실행 시간
n마다 1 ~ n 전부 나눠 보기49,995,0001.87초
n마다 √n까지만 나눠 보기661,6500.034초
배수 방향으로 누적 (이 코드)93,6430.0034초

세 방식의 결과가 완전히 같은 것을 확인했다. 실행 시간은 한 번 측정한 값이라 비율만 참고한다. 배수 방향 누적의 반복 횟수는 limit × (1 + 1/2 + 1/3 + …) 꼴이라 O(N log N)이다.

counts[0]은 0으로 남는다. 인덱스를 숫자 그대로 쓰려고 크기를 limit + 1로 잡은 것이다.

문제 2 — 행성 번호 이동

행성 번호는 네 자리 수(1000 ~ 9999)다. 한 번에 한 자리만 바꿔 다른 행성으로 이동할 수 있고, 두 번호의 양의 약수 개수 차이가 1 이하일 때만 이동이 허용된다. 천의 자리는 0이 될 수 없다. 출발 번호에서 각 번호까지의 최소 이동 횟수를 구한다.

planet_distances.py
from collections import deque


def planet_distances(start, counts):
    distance = [-1] * 10000
    distance[start] = 0
    queue = deque([start])
    while queue:
        current = queue.popleft()
        for place in (1, 10, 100, 1000):
            old = (current // place) % 10
            first = 1 if place == 1000 else 0
            for digit in range(first, 10):
                if digit == old:
                    continue
                neighbor = current + (digit - old) * place
                if distance[neighbor] != -1:
                    continue
                if abs(counts[current] - counts[neighbor]) > 1:
                    continue
                distance[neighbor] = distance[current] + 1
                queue.append(neighbor)
    return distance


counts = divisor_counts(9999)
distance = planet_distances(2023, counts)
print(distance[2225], distance[2123])  # 3 8

자릿수를 산술로 바꾼다

식의미current = 2023, place = 100일 때
(current // place) % 10해당 자리의 현재 숫자2023 // 100 = 20, 20 % 10 = 0
current + (digit - old) * place그 자리만 digit으로 교체digit = 5이면 2023 + 5 × 100 = 2523
first = 1 if place == 1000 else 0천의 자리는 1부터 시도백의 자리이므로 0부터

문자열로 바꿔 한 글자를 갈아 끼우는 방법도 되지만, 정수 연산이 변환 비용이 없어 더 빠르다. 직접 재 보니 같은 BFS가 정수 방식 0.016초, 문자열 방식 0.028초였다.

한 번호의 이웃 후보는 9 + 9 + 9 + 8 = 35개다. 여기에 약수 개수 조건이 걸려 실제 이웃은 훨씬 적다.

천의 자리에 0 허용38예제는 통과, 다른 3,759개 번호의 거리가 달라진다
  • 조건은 "현재 번호와 다음 번호" 사이에 건다. counts[start]가 아니라 counts[current]다. 출발 번호와 비교하면 약수 개수가 6 ± 1인 번호만 다닐 수 있어 2123(4개)에는 영영 못 간다.
  • 천의 자리 0은 예제로 걸러지지 않는다. first 처리를 빼도 주어진 두 예제는 3, 8로 통과한다. 하지만 0으로 시작하는 번호 874개를 경유지로 쓰게 되어 다른 목적지 3,759개의 답이 달라졌다. 예제 통과가 정답을 보장하지 않는 전형적인 경우다.
  • 약수 표를 함수 안에서 만든다. 표는 출발 번호와 무관하다. 한 번 만들어 인자로 넘기면 여러 출발점에 재사용할 수 있다.
  • 목적지마다 BFS를 다시 돈다. 이 함수는 도착점에서 멈추지 않고 distance 전체를 반환한다. 같은 출발점에서 목적지가 여럿이면 한 번의 결과에서 꺼내 쓰면 된다.
  • -1을 0으로 착각한다. 절반 이상의 번호가 도달 불가다. 미방문 표시를 0으로 두면 출발점(거리 0)과 구분되지 않는다.

변형: 이동 경로 복원

교재 범위를 넘어 직접 추가한 변형이다. 위 추적 표의 경로는 이 코드로 뽑았다. 05단원 글의 격자 경로 복원과 같은 원리로, 목적지에서 출발해 "거리가 1 작고 이동 조건을 만족하는 이웃"을 따라 거슬러 올라간다.

planet_path.py
def previous_planet(current, distance, counts):
    for place in (1, 10, 100, 1000):
        old = (current // place) % 10
        first = 1 if place == 1000 else 0
        for digit in range(first, 10):
            if digit == old:
                continue
            neighbor = current + (digit - old) * place
            if (distance[neighbor] == distance[current] - 1
                    and abs(counts[current] - counts[neighbor]) <= 1):
                return neighbor


def planet_path(start, end, counts):
    distance = planet_distances(start, counts)
    if distance[end] == -1:
        return []
    path = [end]
    current = end
    while current != start:
        current = previous_planet(current, distance, counts)
        path.append(current)
    path.reverse()
    return path


counts = divisor_counts(9999)
print(planet_path(2023, 2225, counts))
# [2023, 2523, 2525, 2225]
print(planet_path(2023, 2025, counts))
# []  (도달 불가)

역추적에서도 약수 개수 조건을 다시 확인해야 한다. 거리가 1 작다는 것만으로는 그 번호에서 실제로 넘어올 수 있었는지 알 수 없기 때문이다. 이동 조건이 양방향으로 같은(차이의 절댓값) 문제라서 거꾸로 따라가도 조건이 그대로 성립한다.
